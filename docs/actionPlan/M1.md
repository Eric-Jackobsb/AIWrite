## 二、任务清单

### M1-01 环境搭建

| 项目 | 内容 |
|---|---|
| 目标 | 搭建可编译的工程 |
| 步骤 | 1. 配置 VS 2026 Insiders 的 C++ 工具链（MSVC 14.50，备用 14.44）<br>2. 安装 CMake 3.31.6（独立于系统 PATH，见备注）<br>3. 准备 vcpkg（`C:\dev\vcpkg`，2024-04 版本，基线 `eb0f108…`）<br>4. 创建项目目录 `source/`<br>5. 编写 CMakeLists.txt<br>6. 编写 vcpkg.json |
| 验证 | `build.ps1`（即 cmake --build）成功 |
| 产出 | 可编译的项目 + 构建脚本（build.ps1 / dev.ps1 / install-deps.cmd / CMakePresets.json） |
| 风险 | vcpkg 编译依赖耗时长、误写 C 盘 |
| 对策 | 依赖下载/安装树/二进制缓存全部放 F: 盘；CMake 侧关闭 manifest 自动安装，依赖统一由 install-deps.cmd 维护 |

> 备注（2026-09-22 实测修正）：本机未安装 VS 2022，实际为 **VS 2026 Insiders + MSVC 14.50**；
> 该 vcpkg 快照不含 CMake 4.x 所需的 policy 逃生口，故必须使用 **CMake 3.31.x**（生成器用 Ninja + vcvars64）。

### M1-02 Dear ImGui 集成

| 项目 | 内容 |
|---|---|
| 目标 | 创建窗口，显示 ImGui UI |
| 步骤 | 1. vcpkg 安装 imgui（含 docking/glfw/opengl3 绑定）<br>2. 集成 GLFW + OpenGL 后端<br>3. 创建主窗口<br>4. 显示 "Hello ImGui"<br>5. 运行时加载系统字体（微软雅黑 14px + Consolas 13px，不把字体文件放进仓库） |
| 验证 | 窗口可打开，显示中文 |
| 产出 | 可运行的 ImGui 窗口 |
| 风险 | OpenGL 上下文配置 |
| 对策 | 参考官方示例 |

---

### M1-03 imgui-node-editor 集成

| 项目 | 内容 |
|---|---|
| 目标 | 节点画布可拖拽 |
| 步骤 | 1. 下载 imgui-node-editor 源码并**锁定 v0.9.3**（与 imgui 1.90.7-docking 配对）<br>2. 集成到项目（源码直接编入 third_party/）<br>3. 创建节点编辑器实例<br>4. 添加两个测试节点<br>5. 添加一条连接<br>6. 验证拖拽、缩放、平移 |
| 验证 | 节点可拖动，连接可创建 |
| 产出 | 可交互的节点画布 |
| 风险 | ① 与 ImGui 版本兼容（1.89.55+ 会与其自带 ImVec2 运算符重复定义）<br>② `ed::GetStyle()` 依赖"当前编辑器"，顺序错误会崩溃 |
| 对策 | ① 对 `imgui_extra_math.inl` 打最小补丁（`#ifndef IMGUI_DEFINE_MATH_OPERATORS` 包裹重复运算符）<br>② 必须先 `SetCurrentEditor` 再取样式（已写入代码注释） |

## 三、目录结构

```
source/                        （工程根 = F:\GameDao\Tools\AIwrite\source）
├── CMakeLists.txt
├── vcpkg.json
├── CMakePresets.json          （ninja-debug / ninja-release）
├── build.ps1                  （一键配置 + 编译）
├── dev.ps1                    （MSVC / vcpkg / cmake / ninja 环境）
├── install-deps.cmd           （vcpkg 依赖预装到 F: 盘）
├── README.md                  （开发与调试说明）
├── src/
│   ├── main.cpp
│   ├── ui/
│   │   ├── app.cpp            （窗口 / 主题 / 字体 / 停靠 / 菜单 / 状态栏）
│   │   ├── node_editor_demo.cpp
│   │   └── console_panel.cpp
│   ├── engine/                （M2 起：graph / executor / registry）
│   ├── nodes/                 （M4 起：各节点实现）
│   ├── ai/                    （M4 起：Provider 实现）
│   └── utils/
│       ├── paths.cpp          （~/.brain-ai 目录）
│       ├── log.cpp            （spdlog 双 sink + 环形缓冲）
│       ├── config.cpp         （toml++ 读写 config.toml）
│       └── crypto.cpp         （SHA3-256，M4 PoW 复用）
├── tools/
│   ├── api_probe.cpp          （V-04 / V-05 / V-06）
│   └── webview2_login.cpp     （V-03）
├── third_party/
│   └── imgui-node-editor/     （v0.9.3，源码集成 + 最小补丁）
├── cmake/                     （构建脚本片段）
├── assets/
│   ├── fonts/                 （可选：覆盖用字体；默认用系统字体）
│   └── icons/
└── workflows/
    └── examples/
```

> 构建产物：`AIwrite/build/ninja-debug/bin/`；vcpkg 依赖：`AIwrite/vcpkg-installed/`；vcpkg 缓存：`AIwrite/vcpkg-cache/`。
