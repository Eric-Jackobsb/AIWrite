## 二、任务清单

### M1-01 环境搭建

| 项目 | 内容 |
|---|---|
| 目标 | 搭建可编译的工程 |
| 步骤 | 1. 配置 VS 2026 Insiders 的 C++ 工具链（MSVC 14.50，备用 14.44）<br>2. 安装 CMake 3.31.6（独立于系统 PATH，见备注）<br>3. 准备 vcpkg（`C:\dev\vcpkg`，2024-04 版本，基线 `eb0f108…`）<br>4. 创建项目目录 `source/`<br>5. 编写 CMakeLists.txt<br>6. 编写 vcpkg.json |
| 验证 | `build.ps1`（即 cmake --build）成功 |
| 产出 | 可编译的项目 + 构建脚本（build.ps1 / dev.ps1 / install-deps.cmd / CMakePresets.json） |
| 风险 | vcpkg 编译依赖耗时长、误写 C 盘 |
| 对策 | 依赖下载/安装树/二进制缓存全部放 F: 盘；CMake 侧关闭 manifest 自动安装，依赖统一由 install-deps.cmd 维护 |

> 备注（2026-09-22 实测修正）：本机未安装 VS 2022，实际为 **VS 2026 Insiders + MSVC 14.50**；
> 该 vcpkg 快照不含 CMake 4.x 所需的 policy 逃生口，故必须使用 **CMake 3.31.x**（生成器用 Ninja + vcvars64）。

## 三、目录结构

```
source/                        （工程根 = F:\GameDao\Tools\AIwrite\source）
├── CMakeLists.txt
├── vcpkg.json / vcpkg-configuration.json   （overlay-ports: ["./ports"]）
├── CMakePresets.json          （preset「default」= Visual Studio 18 2026，二进制目录 = ../build）
├── build.ps1                  （一键配置 + 编译）
├── dev.ps1                    （MSVC / vcpkg / cmake 环境）
├── install-deps.cmd           （vcpkg 依赖预装到 F: 盘）
├── README.md                  （开发与调试说明）
├── src/
│   ├── main.cpp               （入口：--console / --login-selftest）
│   ├── ui/
│   │   ├── app.cpp            （窗口 / 主题 / 字体 / 停靠 / 菜单 / 工具栏 / 状态栏）
│   │   ├── editor_state.cpp   （Graph + UndoStack + 示例工作流）
│   │   ├── node_canvas.cpp    （节点画布：渲染 + 全部鼠标交互）
│   │   ├── node_library.cpp   （节点库：9 节点按分类）
│   │   ├── property_panel.cpp （参数面板：9 类控件 + 校验 + 网页版会话区）
│   │   ├── toolbar.cpp        （工具栏：撤销/重做/删除选中/新建/示例 + 运行(UI 占位)）
│   │   ├── theme.h            （分类 / 端口 / 状态配色）
│   │   └── console_panel.cpp  （Console，设计 12.4）
│   ├── engine/                （M2 P1 已落地；M1 期为空目录）
│   │   ├── graph.cpp          （Node/Port/Param/Edge/Graph + 校验 + 参数条件可见性）
│   │   ├── node_registry.cpp  （9 个节点注册表：端口/参数/默认值/枚举）
│   │   ├── undo_stack.cpp     （快照式撤销/重做，深度 50）
│   │   ├── workflow_io.cpp    （工作流 JSON 序列化，设计 §4.7）
│   │   └── (M2-03/04) executor.cpp   工作流执行器（待做）
│   ├── web/                   （M2 W1：网页版登录）
│   │   ├── webview_host.cpp   （内嵌 WebView2 有头登录窗口，独立线程）
│   │   └── session_store.cpp  （内存会话：Cookie 只存内存、退出即销毁）
│   ├── nodes/                 （M4/M5 起：9 个节点实现）
│   ├── ai/                    （M4 起：inference_provider / deepseek_*_provider）
│   └── utils/
│       ├── paths.cpp          （~/.brain-ai 数据目录）
│       ├── log.cpp            （spdlog 双 sink + 环形缓冲）
│       ├── config.cpp         （toml++ 读写 config.toml）
│       ├── crypto.cpp         （SHA3-256，M4 PoW 复用）
│       ├── diagnostics.cpp    （VEH 首异常计数 + 内存采样 + 心跳）
│       └── file_dialog.cpp    （原生文件/目录对话框 nativefiledialog-extended）
├── tools/
│   ├── api_probe.cpp          （V-04 / V-05 / V-06 + --graph-selftest + V-09）
│   └── webview2_login.cpp     （V-03）
├── ports/nativefiledialog-extended/  （overlay port：vcpkg 快照缺此包）
├── third_party/
│   ├── imgui-node-editor/     （v0.9.3，源码集成 + 最小补丁）
│   └── cmake-3.31.6/          （仅供 vcpkg 端口构建使用）
├── cmake/                     （构建脚本片段：运行时 DLL 同步）
├── assets/{fonts,icons}/      （可选覆盖资源；默认用系统字体，目录留空）
└── workflows/examples/        （(M6-03) 6 个示例工作流）
```

> 构建产物：`AIwrite/build/bin/`（VS 2026 生成器，Debug / RelWithDebInfo）；vcpkg 依赖：`AIwrite/vcpkg-installed/`；vcpkg 缓存：`AIwrite/vcpkg-cache/`。
