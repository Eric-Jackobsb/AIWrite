# M_textio：文本输出 —— 预览（最终版）+ 导出为文档

> 类型：功能补丁（**不新增节点类型**，保持 9 节点基线）
> 依据：用户 2026-09-25 决议 —— 导出做成 TextOutput 上的「动作按钮」，不做成图上的节点
> 状态：🟡 计划已定稿（P1 完成）；P2 起按序实施，每步一次提交 + 全量回归

## 0. 决策摘要

| 决策点 | 结论 |
|---|---|
| 节点形态 | **不新增节点**：TextOutput 一个节点承担两个职能 |
| 导出方式 | **动作按钮**（参数面板 + 输出面板），非图上节点 |
| 导出格式 v1 | **.md / .txt**（UTF-8）；.html 可选；**.docx 不做**（不引第三方库） |
| 内容来源 | **与预览同源**（`node_output_text` 同一实现，逐字符一致） |
| 元信息头 | 可选（工作流名 / 时间 / 节点 id / 状态 / 耗时） |
| 节点数 | **保持 9**（不牵连 api_probe 的 `registry.size()==9` 与文档计数） |

## 1. 两个职能

### 1.1 预览输出（最终版文字）
- `TextOutput` = 工作流**最终结果出口**：输出面板该段**置顶 + 高亮**并标注 `最终输出`
- 画布节点摘要前缀 `最终输出：…`；参数面板「运行结果」区同标注
- **`label`（标签）参数真正生效**：作为最终版分段标题 / 文档标题来源
  （现状：`node_registry.cpp` 定义了 `label`，但全仓无任何消费者 → 改了没效果）

### 1.2 导出为文档
- 入口：`TextOutput` 参数面板「导出为文档…」+ 输出面板该节点段「导出为文档…」
- 行为：保存对话框（`utils::save_file`）→ 核心导出函数写盘（**原子写**）→ Console/状态栏提示路径
- 文件名默认 `<工作流名>-<yyyyMMdd-HHmmss>.<ext>`，对话框内可改写

## 2. 核心（可离线断言；UI 只负责取路径）

| 函数（新增 `utils/text_export.{h,cpp}`） | 说明 |
|---|---|
| `render_document_name(workflow, stamp, ext)` | 模板渲染 + 非法字符清洗 + 长度上限 |
| `build_document_body(text, label, meta, include_meta)` | 正文拼接（元信息头可选） |
| `write_document(path, body, overwrite, &error)` | 父目录创建 + **原子写**（临时文件 + rename） |
| `export_text_document(ExportRequest, &error)` | 组合，返回最终路径 |

## 3. 断言（离线，先行）

1. 文件名渲染：工作流名 / 时间戳 / 扩展名；非法字符清洗；长度上限
2. 正文：含 / 不含元信息头；**与 `node_output_text` 逐字符一致**
3. 写盘内容 == 内存 body（读回比对）
4. 同名策略：覆盖 / 自动改名（不覆盖）
5. 目录不可写 → 返回明确错误（不抛出到 UI）
6. 原子写：过程不残留临时文件
7. `label` 生效：最终版分段标题包含标签文本

## 4b. P5（2026-09-25 用户实测反馈修复）

- **修复**：汇点节点（无输出端口）返回值未入运行态值 → 虚拟端口 `__result` + 读取回退（根因：`nodeOutputText` 只遍历 `node->outputs`）
- **新增参数**：`export_dir` / `file_name` / `auto_export`（导出路径与自动导出可配置）
- 断言：`--run-selftest`「汇点结果可读」；回归：6 套 exit 0 + GUI 冒烟

## 5. 明确不做

- 图上的「导出节点」、`.docx`、批量导出多节点、导出模板自定义（v1）
- 不改变 `TextOutput` 的输入端口与既有「透传」语义

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 导出内容与预览不一致 | 同源函数（`node_output_text`）+ 断言 ② |
| 路径非法 / 超长 | 清洗 + 上限 + 断言 ① |
| 写盘失败影响运行 | 导出是**动作**（非运行期），失败只提示、不进 Graph；断言 ⑤ |
| 回归牵连 | 不新增节点 → `registry.size()==9`、节点计数文档保持不变 |
