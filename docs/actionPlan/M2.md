## 二、任务清单

### M2-01 数据结构

| 项目 | 内容 |
|---|---|
| 目标 | 定义核心数据结构 |
| 步骤 | 1. 定义 Node / Port / Param / Edge<br>2. 定义 Graph 类<br>3. 定义 Workflow 类<br>4. 定义 Viewport<br>5. 实现查找/增删方法 |
| 验证 | 可创建图，增删节点和边 |
| 产出 | 数据结构头文件与实现 |

### M2-02 节点注册表

| 项目 | 内容 |
|---|---|
| 目标 | 实现 NodeRegistry 与 registerAllNodes |
| 步骤 | 1. 定义 NodeRegistry 类<br>2. 定义 Definition 结构<br>3. 实现 registerNode / find / listTypes<br>4. 为 9 个节点编写注册函数<br>5. 实现 registerAllNodes |
| 验证 | 可列出所有节点类型，可查找 |
| 产出 | 节点注册表 |

### M2-03 拓扑排序

| 项目 | 内容 |
|---|---|
| 目标 | 实现 Kahn 算法 |
| 步骤 | 1. 计算入度<br>2. 入度为 0 入队<br>3. 依次出队，减少下游入度<br>4. 检测环<br>5. 返回有序节点列表 |
| 验证 | 无环图正确排序，有环图报错 |
| 产出 | topologicalSort 函数 |

### M2-04 执行引擎

| 项目 | 内容 |
|---|---|
| 目标 | 单线程分帧执行 |
| 步骤 | 1. 定义 Executor 类<br>2. 定义节点执行状态机<br>3. 实现 tick 方法<br>4. 实现输入收集<br>5. 实现输出存储<br>6. 实现失败标记与下游跳过 |
| 验证 | 可逐帧执行节点，状态正确 |
| 产出 | 执行引擎 |

### M2-05 JSON 序列化

| 项目 | 内容 |
|---|---|
| 目标 | 工作流保存/加载 |
| 步骤 | 1. 实现 Workflow::toJson<br>2. 实现 Workflow::fromJson<br>3. 实现 Node/Edge 序列化<br>4. 处理版本字段<br>5. 处理缺失字段的默认值 |
| 验证 | 保存后重新加载，图内容一致 |
| 产出 | 序列化模块 |

### M2-06 工作流校验

| 项目 | 内容 |
|---|---|
| 目标 | 三级校验 |
| 步骤 | 1. 加载校验：结构、类型、连接、环<br>2. 运行前校验：必填输入、参数、Provider<br>3. 编辑时校验：连接类型、输入冲突<br>4. 统一错误信息 |
| 验证 | 各类非法工作流被正确拒绝 |
| 产出 | 校验模块 |

### M2-07 撤销/重做

| 项目 | 内容 |
|---|---|
| 目标 | 快照方案 |
| 步骤 | 1. 定义 UndoStack 类<br>2. 实现 push / undo / redo<br>3. 与工作流修改操作集成<br>4. 限制栈深度 50<br>5. 加载工作流时清空 |
| 验证 | 可撤销/重做多次操作 |
| 产出 | 撤销/重做模块 |
