### M4-08 WebView2 登录流程

| 项目 | 内容 |
|---|---|
| 目标 | 手动登录 + Cookie 提取 |
| 步骤 | 1. 创建 WebView2 窗口<br>2. 导航到 chat.deepseek.com<br>3. 用户手动登录<br>4. 提取 Cookie<br>5. 存内存<br>6. 退出时销毁 |
| 验证 | 可登录，Cookie 可用于 API |

> **提前落地（2026-09-23，W1）**：步骤 1~6 已作为「网页版登录」实现并可用——主程序内嵌 WebView2
> 有头登录窗口（`src/web/webview_host.{h,cpp}`，独立线程不阻塞界面）、Cookie 存入内存会话
> `src/web/session_store.{h,cpp}`（退出即销毁、日志脱敏）、参数面板「网页版会话」区块（打开登录窗口 /
> 关闭 / 注销）、状态栏显示推理模式；自检命令 `aiwrite.exe --login-selftest`（实测 PASS / Cookie 5 条）。
> **仍待 M4**：Cookie 注入请求 + PoW 求解 + 定制 SSE 解析（M4-06 / M4-09）。
>
> **进展（2026-09-23，W2 / 协议探明）**：①`--web-probe` 已实测取得网页版鉴权与端点全貌
> （`localStorage.userToken` → `Authorization: Bearer`；`/api/v0/chat/create_pow_challenge`、
> `/api/v0/chat/completion`、`/api/v0/chat_session/{fetch_page,create}`、`/api/v0/users/current`）；
> ② 官方 PoW 头格式已从主包源码读出并与 C++ 实现对齐
> （`X-DS-PoW-Response: base64({algorithm,challenge,salt,answer,signature,target_path})`）；
> ③ `ai/deepseek_web_client.cpp` 已能完成「取挑战 → 调用 completion → 解析 SSE」，
> 服务端已接受请求头（错误从 422/缺 Token 收敛为 `INVALID_POW_RESPONSE`）；
> ④ **PoW 哈希经指纹实测为自定义实现**（非 NIST SHA3-256 / 非 Keccak-256）；
> **已按方案 A 收口**（2026-09-23）：`web::solve_pow_via_page()` 在隐藏登录窗口内调用官方 PoW worker
> 求解（worker chunk 运行时发现，发版自适应），HTTP/SSE 仍由 C++ 完成。
> 实测：`--web-chat "用一句话介绍你自己"` PASS；`--run-selftest --web` **5/5、约 10s**，
> 示例工作流（TextInput → PromptTemplate → LLMGenerate → TextOutput）已能真实出文本。
> 详见 [网页版协议实测记录.md](../网页版协议实测记录.md)。
