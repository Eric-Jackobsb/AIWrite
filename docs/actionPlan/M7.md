### 实测触发本里程碑的真实案例

用户选了 `F:\ims.png` → 参数面板报「无法读取图片信息」，读作"无法识别 PNG"。**根因：该文件扩展名是
`.png`，内容其实是 WebP**（文件头 `52 49 46 46 … 57 45 42 50` = `RIFF….WEBP`，82 910 字节；

```
内容嗅探    : WebP（扩展名 .png；按扩展名的 MIME image/png）
内容 MIME   : image/webp（发给模型时使用）      ← 旧实现会谎报 image/png
扩展名一致  : 否 —— 扩展名与实际格式不一致
WIC 能力    : Windows 图像组件可用；系统已注册 WebP 解码器
本地解码    : OK（解码器 wic，2048×2048，RGBA8 16777216 字节）
结论        : 本地可预览
```

## 1. 事故记录：CRT 断言崩溃（退出码 3 / `0x80000003`）

> 用户反馈「有 assertion error，最近出现频率上升」。本次在 M7-04 落地过程中**复现并定位到根因**。

| 项 | 内容 |
|---|---|
| 症状 | 进程突然结束；退出码 `3` / `-2147483645`（`0x80000003` STATUS_BREAKPOINT）；输出在某一处戛然而止（缓冲丢失）；`app.log` 无"结束"行 |
| 含义 | **Debug 版 CRT/STL 断言被触发**（`_CrtDbgReport` → 中断）；**不是** C++ 异常，`try/catch` 与 SEH 都抓不到 |
| 复现命令 | `build\bin\api_probe.exe --exec-selftest` → 退出码 3（死在 M5-02 图片断言段内） |
| 定位方法 | 在可疑段落插入 **带 `fflush(stdout)` 的 `[TRACE]` 标记**，重定向输出后看最后一个标记（数轮二分把范围从 2000 行缩到 1 个调用） |
| 定位结果 | 最后两个标记：`[TRACE] 1b-准备 decodeErrorMessage（内含 wicInfo…）` → **无后续** ⇒ 死在 `decodeErrorMessage → wicInfo()` |
| 根因 | M7-04 初版用「**30 字节合成 WebP 头**」（`RIFF…WEBP…VP8 `）交给 WIC 的 `CreateDecoderFromStream` **探测系统能力**；本机装有 `Microsoft.WebpImageExtension 1.2.31.0` → 解码器**接受**该假头后去解析比特流 → 断言/中断 |
| 影响面 | `api_probe --exec-selftest` + GUI「面板渲染 WebP 图片」两条路径（后者正是用户观察到的现象来源之一） |
| 修复 | ① 能力探测改为**解码器元数据枚举**（`CreateComponentEnumerator` + `IEnumUnknown` + `IWICComponentInfo::GetFriendlyName`），**不再解析任何比特流**；② 删除 `wic_accepts_bytes` / `synthetic_webp_head` / `synthetic_ftyp_head` 三个危险函数；③ **解码分派收紧**：只有内容嗅探为 WIC 类格式（WebP/TIFF/ICO/JXR/HEIF/AVIF）才调用 WIC，未知 / stb 覆盖的格式一律不进 WIC；④ 失败文案不再依赖探测结果（否则离线断言随机器变化） |
| 冻结 | `utils/image_decode.cpp` 的 WIC 相关代码**冻结**（不变量 **`I17`**）：规则见 `source/README.md` §4.2；`image_decode.h` 顶部加 `#define AIWRITE_IMAGE_DECODE_FROZEN 1` + 三条规则横幅 |
| 回归 | 修复后 `--exec-selftest` **251/0**、`--graph-selftest` 110/0、`--selftest` 七组 PASS、`--run-selftest` PASS；真实 WebP 解码 OK |

> **复现/验收命令**（任何人可复跑）：
> ```powershell
> .\api_probe.exe --exec-selftest            # 应 251/0，退出码 0
> .\api_probe.exe --image-decode F:\ims.png  # 应 exit 0；解码器=wic；2048×2048
> ```
