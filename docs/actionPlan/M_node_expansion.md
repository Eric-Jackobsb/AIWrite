- 「单线程分帧：`tick()` 每帧推进**一个节点**（UI 调用）；无 UI 场景用 `runToCompletion()`」
- 「状态机：`Waiting → Running → Done / Error`；失败节点的下游标 `Skipped`，**无关分支继续**（§10.4）」
- 「运行态**值**只存在于 `Executor`（`NodeOutputs`），**不进入 Graph** —— Graph 是「文档」」

⇒ 三条合起来说明：**现有执行模型是「静态图 + 一次推进」**；上表三项都要求「**控制流**」能力，属**执行引擎语义变更（v2 量级）**。

> **口径结论（`NE-Q3` 已答 · 2026-10-12）**：**留在本文**（不单列 v2 议题）；**将来立项流程 = 将来再定**（`G-2` = C）。
