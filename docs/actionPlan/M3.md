# M3 详细 Action Plan

> 里程碑：M3 节点编辑器 UI
> 版本目标：v0.3
> 预计工期：全职 1–2 周 / 业余 3–4 周
> 前置：M2 完成
> 输出：可视化节点编辑、连接、参数编辑、画布操作

---

## 〇、实施进度（M2 节点系统 P1 + P2 已落地，2026-09-22）

本轮把 M1 的演示画布升级为真实节点系统（数据层 + 画布 + 参数面板 + 撤销重做），
M3 任务清单落地情况如下（详见 [节点编辑器使用说明.md](../节点编辑器使用说明.md)）：

| 任务 | 状态 | 说明 |
|---|---|---|
| M3-01 节点渲染 | ✅ | 分类色条 + 标题 + 节点 id + 状态圆点 + 参数预览 + 校验错误提示；执行态动效（流动边框/绿勾/红叉）属 M4 执行器 |
| M3-02 端口渲染 | ✅ | 输入左圆 / 输出右圆，按类型着色（§4.5），可变长端口双圈；端口标签在面板中显示 |
| M3-03 连接线渲染 | ✅ | 由 imgui-node-editor 绘制贝塞尔曲线；无效连线拖拽时变红（`RejectNewItem`） |
| M3-04 节点操作 | ✅ | 右键分类新建、右键删除（连带连线）、拖拽移动、双击改名（参数面板）已可用；**复制/粘贴已接回**（设计 §6.1：节点右键「复制」、画布右键「粘贴」、编辑菜单「复制/粘贴」；`--run-selftest` 新增 **7 项模型级断言**：新增节点数/连线重映射/位置偏移 ±40 且有限/参数复制/选区与视图跟随/可撤销/空剪贴板拒绝），画布侧保留 `clamp_position` + 未知手柄反向推送 + 视图跟随前校验守卫 |
| M3-05 连接操作 | ✅ | 拖拽创建、类型验证、输入端口替换；删除连线走「左键选中 → 工具栏删除选中」 |
| M3-06 参数面板 | ✅ | 9 类控件 + 必填/范围/枚举/文件存在校验 + 密码框；Color 控件暂无节点使用 |
| M3-07 画布操作 | ✅ | 中键平移、滚轮缩放 0.1x–4.0x（`CustomZoomLevels`）、内置网格可切换 |
| M3-08 节点菜单 | 🟡 | 右键画布 → 5 个分类子菜单（悬停显示端口/参数概要）；节点右键菜单可用；**连线右键菜单按需求移除** |
| M3-09 节点库 | ✅ | 左侧停靠面板，按分类列出 9 个节点，点击添加到画布中心 |
| M3-10 工具栏 | ✅ | 撤销/重做/删除选中/新建/示例 + 计数 + 「打开/保存工作流」+ **「▶ 运行 / ■ 停止」（右对齐，已接执行器）**；复制/粘贴入口按设计 §6.1 放在右键菜单与编辑菜单（工具栏不重复放置，M3-10 清单内本无此项） |

**新增自检**：`api_probe.exe --graph-selftest`（当前 95 项断言 / 95 通过 0 失败），
覆盖注册表、增删、类型兼容矩阵、端口替换、可变长多连线、直接删边、参数校验、撤销/重做与栈深截断、工作流序列化往返。
