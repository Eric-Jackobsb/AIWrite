# M5 详细 Action Plan

> 里程碑：M5 多模态 + 输出
> 版本目标：v0.5
> 预计工期：全职 1–2 周 / 业余 3–4 周
> 前置：M4 完成
> 输出：图片理解链路、输出归档、Output 窗口、示例工作流

> **实施状态（2026-09-26 更新）**：**M5 核心切片（M5-C）已开工** —— 只做「读图生成 + 看得见图片」这条脊柱；

> 模型名走新增的 `model_custom` 自由文本（默认 `glm-4v-flash`，若报模型不存在则改 `glm-5.3-flash`）——
> 同一实现换 `api_base` + 模型名即可对接硅基流动 / 本地 Ollama。
