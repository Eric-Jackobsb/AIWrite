## 4. 9 个节点（设计 §4.4 / §9.2）

| 分类 | 节点 | 输入端口 | 输出端口 | 主要参数 |
|---|---|---|---|---|
| 输入 | 文本输入 `TextInput` | — | `text`(text) | 文本内容（必填） |
| 输入 | 图片输入 `ImageInput` | — | `image`(image) | 图片路径（必填，校验文件存在） |
| 处理 | 提示词模板 `PromptTemplate` | `vars`(any，可变长) | `text`(text) | 模板（必填，`{变量}` 占位） |
| 处理 | 文本合并 `TextMerge` | `texts`(text，可变长) | `text`(text) | 分隔符、忽略空输入 |
| 配置 | 提供商配置 `ProviderConfig` | — | `provider`(provider) | 提供商 / 模式(official,web) / API 地址 / 模型 / API Key（密码框，仅内存） / Key 引用名 |
| 推理 | 文本生成 `LLMGenerate` | `prompt`(text)、`provider`(provider，可选) | `text`(text) | 系统提示词、温度(0~2)、最大长度(1~8192)、Top P(0~1)、流式 |
| 推理 | 图片理解 `VLMGenerate` | `prompt`(text)、`image`(image)、`provider`(provider，可选) | `text`(text) | 同文本生成 |
| 输出 | 文本输出 `TextOutput` | `text`(text) | — | 标签 |
| 输出 | 图片预览 `ImagePreview` | `image`(image) | — | 标签 |

端口颜色（设计 §4.5）：text 白、image 绿、provider 蓝、any 紫（可变长端口多一圈描边）。
连接规则：**同类型可连；`any` 双向兼容；其他不允许**（如 text → image 会被拒绝）。

## 6. 撤销 / 重做（设计 §6.6）

- **快照方案**：每次修改前保存整张图；栈深上限 **50**（超出丢弃最旧）。
- **一次完整操作 = 一次撤销**：创建、删除、重命名提交、连线（新建/替换/删除）、**拖拽移动结束**、**参数编辑结束**（`IsItemDeactivatedAfterEdit`）；复制粘贴已暂停，接回后同样按"一次粘贴 = 一次撤销"计入。
- 产生新操作会丢弃「重做」分支；「新建（清空）」会**清空撤销栈**（设计 §6.6：加载/新建时清空）。
- 撤销/重做后画布选择会被清空（避免指向已不存在的对象）。

## 9. 当前已知限制

1. **无键盘快捷键**（设计 §6.7 明确要求）：已调用 `ed::EnableShortcuts(false)` 关闭画布内置快捷键（含 Delete 删除），请用右键菜单 / 工具栏。
2. **网格固定 32px**（imgui-node-editor 内置网格），设计文档 §6.4 中的「20px」已作废（见该节更新说明）。
3. **参数只存在内存**：退出即丢失；工作流保存/加载在 M2-05，参数持久化在其后。
4. **API Key 仅内存**（参数面板用密码框显示），落 Windows 凭据管理器在 M4-07。
5. **节点状态**目前恒为 `idle`；Running / Done / Error 等状态在执行器（M4）接入后启用。
6. vcpkg 快照缺少 `nativefiledialog-extended`，已用 **overlay port**（`source/ports/nativefiledialog-extended`，v1.3.0）补齐，随 `install-deps.cmd` 一起安装。
7. **复制/粘贴已暂停**：粘贴会新建节点并请求视图跟随，而 `ed::GetNodePosition()` 对"编辑器还不认识"的节点句柄返回 **`FLT_MAX`**（`imgui_node_editor.cpp:1676`），旧代码把它当位置回写模型 → 坐标掉到 ~`-2.1e9` → 视图跟随计算溢出 → 界面无响应（实测卡死点就在粘贴那一帧）。现已：入口下线（逻辑保留）+ 位置守卫（`clamp_position` 夹紧 ±100000、未知句柄改"模型 → 编辑器"推送、视图跟随前校验坐标），M2/M3 重做画布交互时再接回。

## 10. 本轮新增：运行按钮（占位）与网页版登录（W1）

### 10.1 运行按钮（已接线，M2 P3-3）

- **位置**：工具栏**最右端**（顶栏右上角）——「▶ 运行」+「■ 停止」。
- **运行**：点击后先做**运行前校验**（无环 / 必填输入已连 / 参数合法 / Provider 可用性提示）：
  - 校验不过 → **拒绝启动**，每条问题写入 Console（`[运行前校验] …`，红色）与状态栏；
  - 通过 → 每帧推进一个节点，Console 打印 `[执行] …`，画布节点状态圆点实时变色（黄=等待 / 蓝=运行中 / 绿=完成 / 红=失败 / 暗灰=跳过，见 `theme.h`）；
  - 状态栏右侧显示进度：`运行中 | 3/5 | 0.1s | 当前 n3`，结束后显示 `完成 3/5，失败 1，跳过 1，耗时 0.00s（finished）`。
- **停止**：不再开始新节点（正在执行的节点会跑完当前步骤；真正的可中断调用留待 M4 的 HTTP 线程）。
- **运行中修改工作流**（新建/删除/改参数/撤销…）：会**自动终止**本次运行、节点状态复位为 `idle`，并提示「运行已终止（工作流被修改）」。
- **手工验证步骤**：
  1. 启动后点「▶ 运行」→ Console 出现 `[执行] [执行器] 开始执行：共 5 个节点`；
  2. 预期结果：`n1 文本输入 done` / `n2 提示词模板 done` / `n5 提供商配置 done` / **`n3 文本生成 error`（提示「尚未接线」，属 M4 范围）** / `n4 文本输出 skipped`；
  3. 状态栏显示 `完成 3/5，失败 1，跳过 1…`；画布上 n3 红点、n4 变暗；
  4. 想验证「停止」：把 `n3` 断开 `prompt` 连线 → 运行 → 应在运行前校验阶段被拒绝（Console 一行红字）。
- 命令行等价验证：`aiwrite.exe --run-selftest`（同一套 `start_run/tick_run` 代码路径）
  与 `api_probe.exe --exec-selftest`（129 项断言：值传递 / 失败传播 / 取消 / Provider 脱敏等）。

## 11. 工作流文件：打开 / 保存 / 最近打开（M2 P3-6）

- **保存**：工具栏「保存工作流」或菜单「文件 → 保存工作流…」→ 系统保存对话框（默认目录 `~/.brain-ai/workflows`，默认文件名 = 工作流名）。
  - 内容遵循设计 §4.7 schema；**API Key 等 `is_secret` 参数不写入文件**（设计 §8.4）。
  - 成功后写入 `workflow.log`（`[工作流-保存] …`）并进入「最近打开」。
- **打开**：工具栏「打开工作流」或菜单「文件 → 打开工作流…」→ 选择 JSON：
  - 先做**加载校验**（结构引用 / 端口与类型 / 参数 / 环）：不通过则**拒绝加载并保持当前画布不变**（Console 红字说明原因）；
  - 通过后：替换画布内容、**清空撤销栈**（设计 §6.6）、视图跟随新内容、记入最近列表。
- **最近打开**：菜单「文件 → 最近打开 ▸」列出 `~/.brain-ai/recent.json` 中的条目（最新在前，上限 10 条；悬停显示完整路径与最后打开时间），子菜单底部「清空列表」。
- 自动化验证：
  ```powershell
  .\api_probe.exe --selftest      # 含 [V-10] 工作流文件 / 最近列表（往返一致 / 密钥不落盘 / 去重置顶 / 上限 10）
  .\aiwrite.exe --run-selftest    # 含 app 侧「保存 → 打开」往返
  ```

### 10.2 网页版登录（W1）——请逐项确认

1. 画布单击「提供商配置」节点（示例工作流中的 `n5`）→ 右侧**参数**面板；
2. 把**模式**从 `official` 切到 `web`，面板应立即变化：
   - 顶部 `API 地址 / 模型 / API Key / Key 引用名` 四个 official 专属参数**消失**，并提示「（4 个官方 API 专属参数已按当前模式隐藏）」；
   - 底部出现「**网页版会话（Cookie 只存内存，程序退出即销毁）**」区块，状态：**未登录**；
   - 画布上节点卡片的参数预览同步变化（不再显示 API 地址等）；
   - **状态栏**右侧显示 `推理模式: 网页版（未登录）`。
3. 点「**打开登录窗口（WebView2）**」→ 弹出 DeepSeek 登录窗口（跑在**独立线程**，主界面仍可正常操作、不会卡住）：
   - 在窗口内登录 DeepSeek 账号；窗口内 `Ctrl+Alt+C` 立即重新提取 Cookie，`ESC` 关闭窗口；
   - 页面加载完成 / 每 3 秒会自动重取 Cookie：面板状态变为「**已登录（Cookie N 条）**」+ 更新时间 + `ds_session_id` 脱敏值，状态栏变为 `推理模式: 网页版（已登录 N 条 Cookie）`。
4. 点「**关闭登录窗口**」（或直接关窗口）→ 会话**保留在内存**（Cookie 不落盘）。
5. 点「**注销（清会话 + 删除登录 profile）**」→ 会话清空、状态回到「未登录」，并删除 `~/.brain-ai/webview2`（下次需重新登录）。
6. 把模式切回 `official` → 官方参数回来、网页版区块消失、状态栏回到 `推理模式: 官方 API`。

**自动化等价验证（无需手点）**：

```powershell
# 离屏跑「WebView2 环境 → 控制器 → 导航 → 提取 Cookie」并打印脱敏清单
# 退出码 0=通过 / 1=失败 / 2=超时
```

### 10.4 网页版生成（M4-06 已接线，请逐项确认）

**前置**：登录过一次（界面「参数面板 → 网页版会话 → 打开登录窗口（WebView2）」；profile 会记住登录态）。
若内存里还没有凭证，第一次运行时会自动离屏起一次登录窗口做协议探测（约数秒），无需手动操作。

1. 选中「文本生成」节点 → 参数面板「模式」选 **web**（默认已是 web）；「模型」可选
   `deepseek-chat` / `deepseek-reasoner`（深度思考）/ `expert`（专家模式）；
2. 若用「提供商配置」节点，请把它的「模式」也设为 **web/官方网站版**（provider 端口的模式优先）；
3. 连接：`文本输入 → 提示词模板 → 文本生成（prompt）→ 文本输出`，然后点工具栏「▶ 运行」；
4. 预期：状态栏进度推进 → Console 出现
   `[文本生成] 网页版请求…` / `[文本生成] 完成，输出 N 字节` → `[文本输出] …正文…`，
   画布上 4 个节点全部 **done**，状态栏显示「完成 4/4」；
5. 无界面等价验证：`.\aiwrite.exe --run-selftest --web` → 预期 **完成 5/5，失败 0，跳过 0（约 10 秒）**。

**安全边界**：Cookie 与 userToken 仅存内存（退出即销毁），日志/报告一律脱敏；
网页版调用走本机 WebView2 的登录态，不落盘、不外传。

### 10.5 输出面板（PA-02）——请逐项确认

**打开**：菜单「视图 → 输出」（首次切换会持久化到 `config.toml` 的 `[ui] show_output_window`）；
默认与 Console 同区（底部），可拖动分离或停靠到任意位置。

1. 点工具栏「▶ 运行」跑一次（网页版需先登录过一次）；
2. 预期：运行结束后「输出」面板出现逐节点分段——标题形如 `[n3] LLMGenerate · done · 7167 ms`，
   展开后是**完整结果正文**（可滚动）；
3. 点「复制全文」→ 粘贴到任意文本编辑器，应与面板内容一致（UTF-8 无乱码）；
4. 点「导出到文件…」→ 选择保存位置 → 打开导出文件，内容应与面板一致；
5. 展开单个节点 → 点「复制该节点」→ 只复制该节点正文；失败节点显示红色「错误：…」行，
   被跳过的节点标题为 `skipped`（无正文）；
6. 关闭「视图 → 输出」→ 面板隐藏；**重启程序后开关状态被记住**（config.toml `[ui] show_output_window`）。

> 面板**只读**运行结果（不写回节点参数 / 工作流文件 / 撤销栈）；
> 超长正文在面板内最多显示 4 万字符，**复制与导出始终是完整内容**。

### 10.3 安全与边界（设计 §8.5）


- Cookie **只在内存**（`web::SessionStore`），程序退出即销毁；日志与界面一律脱敏（前 4 后 4 + 长度）。
- 登录窗口使用 `~/.brain-ai/webview2` profile → **网页登录态会保留在磁盘**（便于下次免登录）；要彻底清除请用「注销」。
- 网页版推理（PoW 计算 / 定制 SSE / Cookie 注入）**已接线（M4-06）**：`LLMGenerate` 模式选 web 即可真实生成；
  详见 §10.4 与 [网页版协议实测记录.md](网页版协议实测记录.md)。
- 退出保护：若你留着登录窗口直接关主程序，会先关闭登录窗口并等待线程结束（`web::stop_login_window()`），再关日志，避免退出期竞态。

8. **连线右键菜单已移除**：右键连线不再弹出菜单（原「删除连线」「选中该连线」），连线删除请用「左键单击连线选中 → 工具栏【删除选中】」。
9. **画布设置文件损坏会自愈**：`~/.brain-ai/node_editor.json` 保存节点坐标与视图（缩放/平移）。若该文件被写坏（例如残留 ±2^31 坐标或 2e-7 缩放），编辑器每帧网格计算会爆量导致 **CPU 打满、界面无响应**。现已加防护：启动前校验并**自动备份改名重建**（`node_editor_bad_<时间>.json`），运行期检测到异常缩放/原点也会自动重置视图。
10. **诊断日志**：`app.log` 中的 `[诊断]` 行包含：首异常计数（异常时给出**抛出模块**）、30 秒内存采样（工作集/私有/峰值）、渲染循环心跳。若出现卡顿或疑似泄漏，请把这几行发来即可定位。
