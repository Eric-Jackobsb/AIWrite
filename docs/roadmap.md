# AIwrite 长期路线图 v1.0（一页纸）

> 定位：**面向非技术用户**，后期可能转为**商业产品**
> 版本策略：**滚动发布**，内部保留版本号用于追踪，对外不强调
> 数据边界：**全本地**（工作流 / 输出 / 资源 / 日志全在本机；只有 API 请求出网）
> 技术边界：**Windows only**，但新增代码预留跨平台（IPC 抽象、不写死 Win32）
> 长期候选：本地模型、插件系统、节点市场、云同步 —— **均不排期**
> 建立日期：2026-09-27 ｜ 状态：**现行**（**长期路线以本文件为准**；里程碑细节仍见 [actionPlan/](actionPlan/) 各文档）
> 术语：文中「**面向 C**」= 面向（非技术）客户 / 最终用户；「张力 N」= 本次讨论中需要取舍的第 N 处
