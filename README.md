# AIwrite —— AI 小说 / 剧本创作工作台

> **给使用者看的一页纸**（不需要懂编程）。想自己编译 / 改代码请看 [source/README.md](source/README.md)；
> 文档地图在 [docs/DocMAP.md](docs/DocMAP.md)。

用「搭积木」的方式创作：把**文本输入 → 提示词模板 → 文本生成 → 文本输出**四块方块连起来，
点一次「运行」，就能拿到结果。支持的模型分两类：

| 两类模型 | 怎么用 | 需要什么 |
|---|---|---|
| **官方 API**（DeepSeek / 智谱 / Kimi 等官方接口） | 在「参数」面板里选提供商与模型，填入 **API Key** | 自己的 API Key（存本地、加密保存） |
| **网页版站点**（Kimi / 豆包 / 通义 / 文心 / ChatGPT / Claude / Gemini …） | 点「登录」弹出内置浏览器窗口，扫码或账号登录一次 | 一个能登录的账号；不需要 Key |

## 1. 安装

**方式 A（推荐 · 一键安装包）**：双击 `AIwrite-Setup-<版本>.exe` → 下一步即可（可选创建桌面快捷方式）。
安装包**不含 Python 运行时**，也**不会**偷偷装别的软件。

**方式 B（免安装 · 直接跑）**：解压后双击 `aiwrite.exe`（同目录必须带上 `assets\` 与那些 `.dll`）。

> **当前状态（2026-10-10）**：安装包脚本（`packaging\aiwrite.iss` + `source\tools\package.ps1`）已就绪，
> 但**尚未在开发机上编译出成品**（那台机器没装 Inno Setup 且离线）⇒ 现在请先用**方式 B** 运行
> `build\bin\aiwrite.exe`。装好 [Inno Setup 6](https://jrsoftware.org/isdl.php) 后跑一次
> `powershell -File .\source\tools\package.ps1` 即可产出安装包。

## 2. 首次启动会看到什么

1. 自动弹出**「首次使用引导」**（只弹一次，可随时跳过）：
   - **第 1 步 · 环境检查**：报告 WebView2 运行时是否就绪；缺了就给你「打开下载页 / 随包安装 / 重新检测」；
   - **第 2 步 · 载入示例**：一键载入示例工作流（**不用配任何 Key** 也能看到界面与流程）；
   - **第 3 步 · 选模型与凭据**：告诉你去哪选模型、Key 放哪。
2. 主界面分四块：左边**节点库**、中间**节点画布**、右边**参数**、下面 **Console（日志）**与**输出**。
3. 想再看引导：菜单 **帮助 → 首次使用引导**。

## 3. 三步上手

1. **连一根线试试**：中间已经有了示例工作流 → 直接点工具栏的**「运行」**；
2. **看结果**：下方**「输出」**面板里是每个节点的结果全文（也可「复制全文 / 导出到文件」）；
3. **换成自己的题目**：点中「文本输入」节点 → 右边参数面板里改文字 → 再点「运行」。

常用入口速查：

| 想做什么 | 去哪 |
|---|---|
| 新建 / 打开 / 保存工作流 | 菜单 **文件**（「最近打开」里有历史记录） |
| 改设置（面板显示、归档目录、日志保留…） | 菜单 **文件 → 设置…** |
| 看运行日志 | 下方 **Console** 面板；文件在 `%USERPROFILE%\.brain-ai\logs\app.log` |
| 出问题要求助 | 菜单 **帮助 → 复制诊断信息**（把剪贴板内容发给我即可，**里面没有你的密钥**） |

## 4. 常见问题

**Q：双击没反应 / 一开就退？**
先看 `%USERPROFILE%\.brain-ai\logs\app.log` 的最后几行；或菜单 **帮助 → 打开日志目录**。
再不行就把「帮助 → 复制诊断信息」的内容发出来。

**Q：网页版站点点了没用 / 弹不出登录窗？**
多半是缺 **Edge WebView2 运行时**：菜单 **帮助 → 首次使用引导 → 第 1 步**，按提示装完再点「重新检测」。

**Q：官方 API 报「缺少 API Key」？**
Key 有三种放法（优先级从高到低）：① 节点参数里直接填；② 环境变量（如 `DEEPSEEK_API_KEY`）；
③ 存进本地凭据库（推荐）。**Key 只存在你本机**，加密保存、不会上传。

**Q：运行到某个节点就失败了？**
状态栏会变红并给出**可操作的**错误说明（哪一步、为什么、怎么办）；节点卡片上也有红点，
点红点可在右侧看到完整报错。示例工作流里的「官方 API」节点如果没配 Key，失败是**预期**的。

**Q：我的数据都在哪？**
全部在 `%USERPROFILE%\.brain-ai\`：`config.toml`（设置）、`workflows\`（工作流）、
`outputs\`（运行归档）、`assets\images\`（图片资源）、`credentials\`（加密的 Key）、`logs\`（日志）。
**卸载不会删除这个目录** —— 想彻底清理请自己删（删前确认不再需要）。

## 5. 反馈问题时请附上

1. 菜单 **帮助 → 复制诊断信息** 的内容（版本 / 系统 / 依赖 / 路径 / 配置 / 站点表摘要；**不含密钥**）；
2. 复现步骤（点了什么、期望什么、实际什么）；
3. 如与某次运行有关：`%USERPROFILE%\.brain-ai\outputs\<最近一次归档>\` 里的文件。
