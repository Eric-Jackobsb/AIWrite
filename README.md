# AIwrite —— AI 小说 / 剧本创作工作台

> **给使用者看的一页纸**（不需要懂编程）。想自己编译 / 改代码请看 [source/README.md](source/README.md)；
> 文档地图在 [docs/DocMAP.md](docs/DocMAP.md)。

用「搭积木」的方式创作：把**文本输入 → 提示词模板 → 文本生成 → 文本输出**四块方块连起来，
点一次「运行」，就能拿到结果。支持的模型分两类：

| 两类模型 | 怎么用 | 需要什么 |
|---|---|---|
| **官方 API**（DeepSeek / 智谱 / Kimi 等官方接口） | 在「参数」面板里选提供商与模型，填入 **API Key** | 自己的 API Key（存本地、加密保存） |
| **网页版站点**（Kimi / 豆包 / 通义 / 文心 / ChatGPT / Claude / Gemini …） | 点「登录」弹出内置浏览器窗口，扫码或账号登录一次 | 一个能登录的账号；不需要 Key |

## 2. 首次启动会看到什么

1. 自动弹出**「首次使用引导」**（只弹一次，可随时跳过）：
   - **第 1 步 · 环境检查**：报告 WebView2 运行时是否就绪；缺了就给你「打开下载页 / 随包安装 / 重新检测」；
   - **第 2 步 · 载入示例**：一键载入示例工作流（**不用配任何 Key** 也能看到界面与流程）；
   - **第 3 步 · 选模型与凭据**：告诉你去哪选模型、Key 放哪。
2. 主界面分四块：左边**节点库**、中间**节点画布**、右边**参数**、下面 **Console（日志）**与**输出**。
3. 想再看引导：菜单 **帮助 → 首次使用引导**。

## 3. 三步上手

1. **连一根线试试**：中间已经有了示例工作流 → 直接点工具栏的**「运行」**；
2. **看结果**：下方**「输出」**面板里是每个节点的结果全文（也可「复制全文 / 导出到文件」）；
3. **换成自己的题目**：点中「文本输入」节点 → 右边参数面板里改文字 → 再点「运行」。

常用入口速查：

| 想做什么 | 去哪 |
|---|---|
| 新建 / 打开 / 保存工作流 | 菜单 **文件**（「最近打开」里有历史记录） |
| 改设置（面板显示、归档目录、日志保留…） | 菜单 **文件 → 设置…** |
| 看运行日志 | 下方 **Console** 面板；文件在 `%USERPROFILE%\.brain-ai\logs\app.log` |
| 出问题要求助 | 菜单 **帮助 → 复制诊断信息**（把剪贴板内容发给我即可，**里面没有你的密钥**） |

## 4. 设置（菜单「文件 → 设置…」）

设置全部存在 `%USERPROFILE%\.brain-ai\config.toml`；界面改完点**「保存」**才写盘
（写前自动备份为 `config.toml.bak`）。分 9 个折叠区，除特别标注外**保存即生效**：

| 分区 | 能改什么 | 生效时机 |
|---|---|---|
| **界面** | 显示节点库 / 参数面板 / Console / 输出面板；画布显示网格；运行中动效；Console 高度；网格间距 | 面板可见性**保存即生效**；「网格间距」当前版本**暂不生效**（只读展示，尚未接线） |
| **输出与归档** | 归档目录（可点「选择目录…」）；完成后自动打开归档目录；保留多份历史归档（及份数）；归档清理阈值（天） | 保存即生效；`~` 自动展开为用户主目录 |
| **网络超时** | 连接超时 / 首字节超时 / 流空闲超时（毫秒） | 官方 API 的**默认**超时；站点表声明了 `limits.*` 时**以表为准** |
| **网络与证书** | 代理地址；自动读取环境变量；NO_PROXY；自签证书兼容 | 保存即生效；「自签证书兼容」打开会红字提示 **⚠ 危险**（仅内网/离线） |
| **错误与重试** | 自动重试失败节点；重试次数；重试间隔 | 只对**可重试**失败重试（429 / 5xx / 网络超时）；凭据 / 余额 / 请求不合法不重试 |
| **凭据库** | 保存目录；保留天数（0 = 不清理）；后端（只读：dpapi） | Key 以 Windows DPAPI 加密保存（不落明文）；「保留天数」的**清理动作下次启动执行** |
| **高级** | logs 保留天数（0 = 不清理）；打开日志 / 数据目录 | 「logs 保留天数」的**清理动作下次启动执行**（app.log / workflow.log 永不删） |
| **提供商与站点表** | 配置表错误/警告原文；「新建网页版站点…」；「重新加载配置表」；打开用户配置表目录 | 新建 / 重载都**无需重启**，下拉即时出现 |
| **数据安全** | 启用自动保存；静默多少秒写快照；保留历史快照份数；启动时提示恢复 | 保存即生效 |

> 底部「恢复默认值」只重置上面这些设置（窗口几何 / 首启标记 / 多提供商参数不受影响）；再点「保存」才真正写盘。

## 5. 模型、凭据与官方 API

### 5.1 官方 API Key 放哪（三种方式，优先级从高到低）

1. **节点参数里直接填**（只对这一个节点生效）；
2. **环境变量**（如 `DEEPSEEK_API_KEY`；各厂商认哪些变量，见「提供商」下拉里的提示）；
3. **本地凭据库**（推荐）：菜单 **文件 → 设置 → 凭据库**，或首次使用时按界面提示存入。

Key **只存在你本机**：用 Windows DPAPI 加密后落在 `%USERPROFILE%\.brain-ai\credentials`（**不落明文**、不上传）。
「保留天数」到期的 Key 在启动时清理，界面有「即将过期」提示。诊断信息 / 日志 / 归档一律**脱敏**，不含密钥。

### 5.2 网页版站点：登录与「会话失效」

网页版站点（Kimi / 豆包 / 通义 / ChatGPT / Claude / Gemini…）用**登录**而不是 Key：在「提供商」下拉选站点 → 点**「登录」**
弹出内置浏览器窗口，扫码 / 账号登录一次即可，登录态保存在本机（该站点的 Cookie）。

**会话失效**（登录过期 / 被踢下线）时，运行会给出**可操作**的提示：状态栏与节点卡片会标出「重新登录」入口 ——
重登一次即可，**不必重启程序**。

### 5.3 流式与「分段落定」（当前行为说明）

当前版本**不提供逐字流式输出**：官方 API 与网页版站点都是**等整段结果完成后一次性返回**全文
（网页版按页面的「完成判据」判断生成是否结束）。想要长文，请用「文本生成」节点 + 多次运行，
或把内容拆成多段分别生成（网页版文案按「**分段落定**」说明）。

## 6. 常见问题

**Q：双击没反应 / 一开就退？**
先看 `%USERPROFILE%\.brain-ai\logs\app.log` 的最后几行；或菜单 **帮助 → 打开日志目录**。
再不行就把「帮助 → 复制诊断信息」的内容发出来。

**Q：网页版站点点了没用 / 弹不出登录窗？**
多半是缺 **Edge WebView2 运行时**：菜单 **帮助 → 首次使用引导 → 第 1 步**，按提示装完再点「重新检测」。

**Q：官方 API 报「缺少 API Key」？**
Key 有三种放法（优先级从高到低）：① 节点参数里直接填；② 环境变量（如 `DEEPSEEK_API_KEY`）；
③ 存进本地凭据库（推荐）。**Key 只存在你本机**，加密保存、不会上传。

**Q：运行到某个节点就失败了？**
状态栏会变红并给出**可操作的**错误说明（哪一步、为什么、怎么办）；节点卡片上也有红点，
点红点可在右侧看到完整报错。示例工作流里的「官方 API」节点如果没配 Key，失败是**预期**的。

**Q：我的数据都在哪？**
全部在 `%USERPROFILE%\.brain-ai\`：`config.toml`（设置）、`workflows\`（工作流）、
`outputs\`（运行归档）、`assets\images\`（图片资源）、`credentials\`（加密的 Key）、`logs\`（日志）。
**卸载不会删除这个目录** —— 想彻底清理请自己删（删前确认不再需要）。
